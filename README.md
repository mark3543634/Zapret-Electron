# Zapret Electron

> GUI для обхода DPI-блокировок на Windows — YouTube, Telegram, Discord, Roblox и другие сервисы.

Минималистичный пиксельный интерфейс с несколькими взаимозаменяемыми способами обхода.
Не требует ручной настройки — оставь режим «Авто» и нажми запустить.

## Возможности

### Стратегии обхода
- **Пять движков** — Zapret/winws, ByeDPI, DPIBreak, GoodbyeDPI и GreenTunnel в одном строгом интерфейсе
- **Автоматический режим** — выбирает полный Zapret на обычных ПК и вариант без драйвера на HP, где защитный сетевой фильтр может мешать WinDivert
- **Без конфликтов** — приложение запускает только один движок и завершает только собственный процесс, не трогая другие экземпляры
- **Комбо** — одновременно TG + YouTube + Discord + Roblox
- **Универсал 1–10** — разные методы обхода DPI под разные провайдеры
- **Автосовместимость HP** — работает с любой выбранной стратегией и автоматически подготавливает требуемые параметры TCP

### Автоматика
- **Автоподбор** — тестирует все стратегии на твоих сайтах и выбирает лучшую
- **Память сети** — сохраняет рабочую стратегию отдельно для каждого Wi-Fi или проводного подключения
- **Автопочинка доступности** — по желанию перепроверяет сервисы и запускает автоподбор только после трёх подтверждённых сбоев при работающем интернете
- **Watchdog** — если движок упал, перезапускает автоматически без участия пользователя
- **Честный статус запуска** — приложение показывает «Активен» только после подтверждения перехвата WinDivert; после трёх неудачных попыток перезапуск прекращается с понятной ошибкой
- **История автоподбора** — при запуске показывает результат последнего теста
- **Автозапуск** — приложение запускается вместе с Windows в трее; обход включается вручную
- **Тихий режим** — фоновые действия выполняются без лишних уведомлений
- **Обновление списков** — актуальные списки сайтов и Telegram-прокси загружаются при запуске и каждые 30 минут
- **Безопасное обновление приложения** — проверка GitHub Releases, обязательная сверка SHA-256 и возможность отката

### Telegram-прокси
- **Локальный Telegram WS** — рекомендуемый режим поднимает собственный прокси на `127.0.0.1:1443` и направляет Telegram Desktop через WebSocket/TLS
- **Без случайного посредника** — локальный режим не зависит от доступности публичных MTProto-серверов
- **Резервные маршруты** — при недоступности основного WebSocket модуль пробует CfProxy или прямое TCP-подключение
- **Ручное управление** — локальный прокси включается пользователем, не добавляется в автозагрузку и останавливается вместе с приложением
- **Публичный резерв сохранён** — прежние MTProto/SOCKS5 и автопоиск доступны отдельным запасным блоком
- **Свежие источники** — автопоиск сначала загружает актуальные MTProto-прокси из сети
- **Проверка доступности** — до 20 адресов проверяются одновременно без перегрузки сетевого стека
- **Безопасный кэш** — пустой или повреждённый ответ не заменит рабочий список; при сбое сети используется последняя корректная копия
- **Повторная проверка** — лучшие кандидаты проходят три подключения; учитываются средняя задержка и её разброс
- **Пул резервов** — сохраняются пять стабильных прокси, которые перепроверяются в фоне каждые 10 минут
- **Автоподмена резерва** — если выбранный адрес перестал отвечать, приложение подготавливает следующий рабочий вариант

### DNS
- **Отдельная вкладка** — DNS включается и выключается независимо от DPI-обхода и Telegram-прокси
- **AdGuard dnsproxy** — отдельный проверяемый DNS-движок с кэшем, параллельными upstream и резервами; встроенная реализация остаётся аварийным запасом
- **Защищённый DNS** — локальный DoH через Cloudflare/Google шифрует DNS-запросы, но не меняет регион
- **Smart DNS для нейросетей** — запросы к Comss.one идут через зашифрованный DoH; при его недоступности используются два резервных сервера Comss
- **Совместимость с Zapret** — текущие стратегии не перехватывают DNS-порт 53, поэтому профили можно использовать вместе с обходом
- **Безопасное восстановление** — исходные настройки возвращаются после выключения профиля, полного выхода и аварийного завершения приложения
- **Резерв и контроль здоровья** — активный профиль проверяется каждую минуту; рабочий Smart DNS становится основным, а после трёх полных отказов приложение возвращает исходные настройки

При одновременном использовании Smart DNS и Zapret отдельный поддерживаемый сервис может зависеть от маршрутизации оператора Smart DNS. Если он перестал открываться, временно остановите обход и повторите проверку. Smart DNS является сторонним сервисом, не скрывает IP-адрес и не заменяет VPN.

### Система и диагностика
- **Определение причины** — последовательная проверка интернета, системного DNS, публичного DoH, IPv4/IPv6, TCP 443, TLS 1.2/1.3, SNI и HTTPS
- **Осторожная диагностика ТСПУ/DPI** — приложение показывает вероятную фильтрацию только когда контрольный интернет и DNS работают, но TLS к выбранному сервису обрывается
- **Поиск конфликтов** — активные VPN/TUN-адаптеры, системный прокси, занятый DNS-порт 53, оставшийся `127.0.0.1` и несколько процессов `winws.exe`
- **Диагностика HP** — модель устройства, Wolf Security/Sure Click/Velocity, HVCI/VBS, архитектура ARM64 и события блокировки WinDivert
- **Проверяемые сервисы** — YouTube, Discord, Telegram, ChatGPT и Gemini
- **Безопасный отчёт** — сохраняется на рабочий стол без паролей, прокси-секретов и содержимого браузера
- **Обновление внутри приложения** — проверка, загрузка, SHA-256-контроль и запуск установщика выполняются без посещения GitHub

- DNS вынесен в отдельную вкладку с независимым управлением, состоянием совместимости и проверкой разрешения доменов.
- Исходный DNS восстанавливается при полном выходе, завершении сеанса Windows и аварийном закрытии через отдельный процесс-страховщик.
- Smart DNS не является VPN: он не скрывает IP и помогает только с доменами, которые поддерживает оператор DNS.

### Мониторинг
- **Пинг-монитор** — задержка до YouTube и Discord, обновляется каждые 5 секунд
- **Таймер работы** — сколько времени движок активен

### Удобство
- **Горячая клавиша** `Ctrl+Shift+Z` — старт/стоп без открытия окна, работает в любом приложении
- **Тихий старт** — при автозагрузке Windows окно не появляется, только иконка в трее
- **Управление из трея** — старт/стоп, автоподбор, обновление списков, Telegram-прокси и настройки без открытия главного окна
